# coach-app

Coaching Web-App und PWA — gebaut mit Next.js 14, Supabase und Tailwind. Deployed auf Vercel.

## Lokal entwickeln

```bash
npm install
cp .env.example .env.local
# .env.local mit echten Supabase-Werten ausfuellen
npm run dev
```

App laeuft dann auf http://localhost:3000.

## Tech-Stack

- Next.js 14 (App Router)
- Supabase (DB + Auth + RLS)
- Tailwind CSS
- TypeScript
- Vercel Hosting
